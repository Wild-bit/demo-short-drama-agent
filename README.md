## 协作方式

- 用户亲手创建实现文件、配置和编写代码。
- 文档先行：助手先为当前小步骤写清概念、业务例子、运行过程和验证目标。
- 用户先阅读、提问并复述理解；理解后，助手再指导创建文件和编写当前步骤的代码。
- 每次只推进一个小步骤，说明目的、输入输出和验证方法。
- 用户完成后，助手读取代码与运行结果，指出问题，再进入下一步。
- 除非用户明确要求代写，助手不直接创建或修改实现代码，也不提前搭建后续功能。
- 学习与项目实现同步推进；理解并验证后，再提炼为分享 PPT。
